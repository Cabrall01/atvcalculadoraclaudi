# Calculadora de Divisão de Conta

Projeto prático desenvolvido em JavaScript para calcular o valor total da conta de um restaurante e a divisão igualitária entre o número de pessoas na mesa.

## 📁 Estrutura do Projeto

```
calculadora-divisao-conta/
├── index.html
├── script.js
└── README.md
```

## 🚀 Como Executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web.
3. Responda aos alertas que solicitam o valor total da conta e a quantidade de pessoas.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **JavaScript**: Lógica de entrada de dados, cálculo e exibição do alerta.
